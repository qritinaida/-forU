# 💖 ขอบคุณที่เข้ามาในชีวิต (Cute Thank You Webpage)

เว็บเพจบอกความรู้สึกน่ารักๆ อบอุ่น เพื่อบอก "ขอบคุณที่เข้ามาในชีวิต" พร้อมเพลงประกอบ **Dept - 17 (Lucky)** เปิดคลอเบาๆ แบบอัตโนมัติเมื่อเปิดซองจดหมาย ออกแบบมาให้รองรับมือถือและคอมพิวเตอร์อย่างสมบูรณ์แบบ ไม่มีรูปภาพ เน้นส่งต่อความรู้สึกผ่านตัวหนังสือและอนิเมชันน่ารักๆ

---

## ✨ ฟังก์ชันเด่น (Features)
- 💌 **Intro ซองจดหมาย 3D**: แตะเพื่อเปิดอ่านจดหมาย พร้อมเริ่มเล่นเพลง Dept คลอเบาๆ ทันที
- 🎵 **Floating Music Player**: แผ่นเสียงหมุนน่ารัก ปรับระดับเสียงได้ ควบคุมหยุด/เล่นเพลงได้ตลอดเวลา
- ⏳ **ตัวนับวันเวลา (Days of Warmth)**: นับเวลาที่รู้จักกันแบบ Real-time (วัน, ชั่วโมง, นาที, วินาที)
- 🎶 **ท่อนเพลงไฮไลท์**: *"ผู้คนมีมากมายเป็นล้าน แต่ฉันโชคดีเหลือเกินที่ได้พบกับเธอ"*
- 📜 **จดหมายความรู้สึก**: ข้อความแทนใจสไตล์กระดาษโน้ตและเทปวาชิ
- 🌸 **เหตุผลเล็กๆ ที่อยากขอบคุณ**: การ์ดข้อความน่ารักๆ แตะเปิดอ่านความในใจ
- 🎁 **แคปซูลความรู้สึก**: สุ่มข้อความกำลังใจและรอยยิ้ม
- 💖 **ปุ่มส่งหัวใจ**: กดส่งหัวใจรัวๆ พร้อมเอฟเฟกต์หัวใจลอยฟุ้ง
- 📱 **Responsive 100%**: สวยงามทั้งบน iOS, Android, iPad และ Desktop

## 🛠️ วิธีปรับแต่งข้อความส่วนตัว (Customization)
คุณสามารถแก้ไขชื่อ วันที่ หรือข้อความได้ง่ายๆ ในไฟล์ **`js/config.js`** เพียงไฟล์เดียว:

```javascript
const CONFIG = {
    // 1. ชื่อของคุณและคนพิเศษ
    recipientName: "เธอคนพิเศษ",    // เปลี่ยนเป็นชื่อแฟน/คนพิเศษ เช่น "น้องพิม"
    senderName: "เราเอง",           // เปลี่ยนเป็นชื่อคุณ

    // 2. วันที่เริ่มรู้จักกัน หรือวันพิเศษ (รูปแบบ: YYYY-MM-DD หรือ YYYY-MM-DDTHH:mm:ss)
    startDate: "2024-01-01T00:00:00",

    // 3. YouTube Video ID (เริ่มต้นคือ Dept - 17 (Lucky))
    youtubeVideoId: "LXIEBWnqiBA",
    
    // 4. ระดับเสียงเริ่มต้น (0 - 100) แนะนำ 25 เพื่อให้เปิดคลอเบาๆ
    defaultVolume: 25,

    // ... สามารถแก้ไขข้อความจดหมาย และเหตุผลที่ขอบคุณได้ทั้งหมดในไฟล์นี้!
};
```

## 🚀 วิธีนำขึ้น GitHub และเปิดออนไลน์ (GitHub Pages)

### ขั้นตอนที่ 1: สร้าง Repository บน GitHub
1. ไปที่ [GitHub.com](https://github.com) แล้วเข้าสู่ระบบ
2. กดปุ่ม **`New`** (หรือเครื่องหมาย `+` มุมขวาบน) เพื่อสร้าง Repository ใหม่
3. ตั้งชื่อ Repository เช่น `thank-you` หรือ `for-you`
4. เลือกเป็น **Public**
5. **ไม่ต้อง** ติ๊กช่อง Add a README file (เพราะในโฟลเดอร์นี้มีไฟล์แล้ว)
6. กด **`Create repository`**

### ขั้นตอนที่ 2: อัปโหลดโค้ดขึ้น GitHub
เปิด Terminal / Command Prompt ในโฟลเดอร์นี้ แล้วพิมพ์คำสั่ง:

```bash
# 1. เชื่อมต่อกับ Repository ของคุณ (เปลี่ยน YOUR_USERNAME และ YOUR_REPO ให้เป็นของคุณ)
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git

# 2. ตั้งชื่อ branch หลักเป็น main
git branch -M main

# 3. อัปโหลดขึ้น GitHub
git push -u origin main
```

*(หากใช้ GitHub Desktop หรือ VS Code สามารถกด Publish Repository ได้ในคลิกเดียวเช่นกัน)*

---

### ขั้นตอนที่ 3: เปิดใช้งานเว็บออนไลน์ฟรี (GitHub Pages)
1. ในหน้า Repository บน GitHub ให้ไปที่แถบ **`Settings`** (ด้านบน)
2. เมนูด้านซ้าย เลือก **`Pages`**
3. ตรงส่วน **Branch**:
   - เปลี่ยนจาก `None` เป็น **`main`**
   - โฟลเดอร์เลือก **`/(root)`**
4. กดปุ่ม **`Save`**
5. รอประมาณ 1-2 นาที คุณจะได้ลิงก์เว็บไซต์ เช่น:
   ```
   https://YOUR_USERNAME.github.io/YOUR_REPO/
   ```
6. สามารถคัดลอกลิงก์นี้ ส่งให้คนพิเศษเปิดบนมือถือได้ทันที! 💌✨
